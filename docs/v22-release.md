# V2.2 / 研究机制与审核闭环

上传整理日期：2026-09-22。功能在本地开发分支交付；公开静态演示保持早期版本。本版本无新增运行依赖。

## 已实现

- **核验可信度**：数值通过与审核分开；Disclosed 输入一致标为独立披露值数值一致，Calculated 输入仅标为计算自洽。AMD 负债由资产减权益推导时标记依赖，不能反向证明报表正确。尚未实现通用公式依赖图；未知衍生链保守标识。
- **经营驱动模型**：硬件以量价指数和单位成本驱动；订阅以留存、扩张、新增客户及当年确认比例驱动。未来资金占用以应收、存货、应付天数假设计算，传导到五年 FCFF。缺失经营数量时使用明确假设的指数，不伪造销量或客户数。
- **模型修订**：保存输入、依据、反证、推翻条件和父版本；展示参数变化及收入、经营利润、资金占用、FCFF 差额。旧快照不可覆盖，新披露将关联研究标为待复核。
- **逐指标比较**：分别判断金额与比率；不同币种的金额不直接比较，比率在其他条件满足时允许有条件参考。净利润非正时不把 CFO/净利润解释为通常的现金转化质量。同行含 NVIDIA、AMD、Intel；Adobe 验证另一商业模式。
- **业务与产品判断**：按公司、业务分部、产品／客户场景记录差异，必须附双方来源、经营机制、其他解释和推翻条件。比较快照冻结当时数据；同行更新也触发复核。
- **任务引导**：从现金、竞争、增长三类问题开始，再进入相关工具。研究判断保存状态、模型关联和修订原因。
- **提取审核**：本地规则识别单行指标数值，歧义行留空；允许导入外部候选 JSON。逐条接受、修正或拒绝，保留原建议与处理理由；另行确认导入。外部文本无工具权限，不执行文档指令。

## 明确边界

这是简化经营模型，未完成全资产负债表、融资、税损、合同负债与每股估值。硬件合并收入指数并非真实单品量价分解；订阅基期收入暂作经常性运行率是强假设，不是披露 ARR。同一参数在五年内不变，结果是情景，不是概率区间。

新公司的行业专属模型仍需扩展，金融机构不使用这两类模型。自动获取任意公司资料、PDF 表格抽取、外部模型在线调用和独立提取准确率评估尚未完成。审核接受率只是一种操作统计，不是准确率。用户没有被标记为已完成数据审核或设计验收。

## Reproducible case / 可复现案例

运行 `python -B scripts/build_research_case.py`，每次生成新的独立目录，不覆盖日常库。输出数据库、manifest.json、AMD 研究包和 Adobe 模型包。

AMD 练习流程：三家半导体比较 → 建立量增长 10%、价格不变的假设 → 增加价格每年 -5% 压力情景 → 保存判断 → 冻结历史管理层季度收入指引 → 导入后来披露收入 → 检验误差 → 修订判断，同时保留“不能由收入单项确认竞争机制”的限制。全部研究文字为 AI 起草的演示，不是用户已独立完成的研究。

本地示例生成结果（USD million）：

| 首年 | 基准假设 | 价格压力假设 |
|---|---:|---:|
| 收入 | 28,363.50 | 26,945.33 |
| 经营利润 | 2,631.25 | 1,213.08 |
| 增量资金占用 | 993.25 | 652.69 |
| FCFF | 1,111.75 | 317.77 |

以上是本项目程序按练习参数计算的结果，不是公司指引。来源基础是 [AMD FY2024 年报](https://ir.amd.com/financial-information/sec-filings/content/0000002488-25-000012/amd-20241228.htm)。

管理层 Q1 FY2025 收入指引为 7,100 ±300，随后披露收入 7,438；案例计算绝对误差 338、绝对百分比误差 4.54%，实际高于指引上界。此为管理层历史指引复盘，不是用户独立预测的成绩。[原指引](https://ir.amd.com/financial-information/sec-filings/content/0000002488-25-000009/q42024991.htm)，[后来披露](https://ir.amd.com/financial-information/sec-filings/content/0000002488-25-000045/q12025991.htm)。

Intel 数据来自 [FY2024 业绩公告](https://www.intc.com/news-events/press-releases/detail/1726/intel-reports-fourth-quarter-and-full-year-2024-financial)，保留未审计报表属性。使用合并净利润，区别于归属于 Intel 的净利润；分部收入包含内部交易，不能直接相加计算市场份额。

## 测试与审核边界

后端测试：既有 28 项与新增 18 项。新测试包括手算量价、订阅确认与期末运行率区别、回款天数变化对现金影响、衍生勾稽、跨币种指标、同行更新提醒、不可覆盖修订、草稿/审核/导入分离、重复导入拒绝、跨公司草稿隔离及文本不执行。

浏览器脚本 `qa-research.cjs` 检查新研究闭环及 1280/390 宽度；`qa-workspace.cjs`、`qa-workbench.cjs` 保留原有流程。测试使用独立数据库和 D 盘浏览器配置，未上传运行库、截图缓存或用户笔记。

这些是程序功能验证；没有用户行为实验、研究效率提升证据或通用 AI 准确率结论。公开代码不含密钥，服务仅供本机；多用户部署需另做身份验证与数据隔离。

## 下一步建议

优先人工核对两份完整案例，补齐经营数据与来源定位，再决定是否接入外部提取模型。不要把界面里可填写的假设当成已经完成的行业研究；完整三表与更细行业模型应按实际数据可得性逐步建立。
