# V2.1：从单案例界面到多公司研究工作流

实施与验证日期：2026-09-19。本文记录当前实现；V2 文档中的 16 项测试和七页面为历史版本。

## 产品问题与成功标准 / Problem brief

用户提出：表格不足，功能入口难懂，不能只分析预置公司，竞品对比需要解释差异，核心必须是财务数据之间的逻辑，颜色由用户自己决定。

本轮成功标准：新建公司后能导入有来源的财务数据；数值能追溯；勾稽缺失与差额可定位；比较先检查口径；不借公司名称编造数据；新流程与原有预测、审核、备忘录可连接；换色不修改研究内容。

## 实際程序逻辑

公司档案 → 来源与披露日期 → 标准化指标 → 勾稽与缺失检查 → 财务诊断与可比性 → 经营假设 → 确定性预测 → 保存判断 → 后续实际值检验。

1. **公司档案**分别保存行业、商业模式、报表范围、会计准则、币种和模型类别。支持自定义代码，不要求公司已上市。创建档案不会生成指标。
2. **证据与标准化**保存来源链接、页码或表名、披露日期、期间起止、原始金额和单位。支持 USD/CNY/EUR/HKD/JPY/GBP，以及基础单位、千、万、百万、十亿，计算统一为原币种的百万，不自动换汇。
3. **财务语义层（semantic layer）**将收入、费用、现金等字段映射到指标字典。净利润不是经营现金流；期间流量不是期末余额；非 GAAP 指标不能通过主报表导入冒充 GAAP。
4. **计算与勾稽**由程序完成。缺少输入保留为空，不视为零。核心损益缺失或不平、资产负债不平时阻止一般企业预测。
5. **研究判断**由研究者写明支持、反证、推翻条件，再关联经营参数。不会把市场事件直接变成确定的销量影响。
6. **更新**保留旧快照，新增资料后将同公司模型、论点、备忘录标记待复核。目前是公司级提醒，并非精确字段依赖图。

Point-in-time（研究时点）按披露日期过滤输入。导入未来披露后提供显式调整研究日期按钮，不自动改变历史研究时点。研究记录另保留真实创建时间，不把回溯练习伪装成当时预测。

## 勾稽规则 / Financial reconciliation

| 关系 | 处理方式 |
|---|---|
| 收入 − 成本 = 毛利 | 输入来自同公司、期间和主报表口径 |
| 毛利 − 经营费用 + 其他经营收益 = 经营利润 | 档案明确选择是否存在单列其他收益；不得默认为零 |
| 资产 = 负债 + 权益 | 差额单列，不能据此直接认定造假 |
| 净利润 + 非现金调整 + 经营营运资本现金变动 = CFO | 调整项缺失即显示缺项 |
| CFO + CFI + CFF + 汇率影响 = 现金净变动 | 缺汇率影响不补零 |
| 期初现金 + 净变动 = 期末现金 | 使用现金流量表范围 |
| 资产负债表现金 + 受限现金 = 现金流量表期末现金 | 核查范围不同造成的差异 |
| 期初留存收益 + 净利润 − 股利 + 其他调整 = 期末留存收益 | 其他调整必须明确提供 |
| 利息收入 − 利息支出 = 净利息收入 | 金融模板替代通用毛利、经营利润规则 |

容差默认 0.01 个百万呈报货币单位，是本项目的舍入处理设置，不是审计重要性水平。规则通过不等于审计通过，也不代表数据完整。

真实案例：AMD FY2024 毛利 12,725、经营费用 10,873、许可收益 48、经营利润 1,900；忽略许可收益会造成 48 的错误差额。现金流量表期末现金 3,811，与现金及等价物 3,787 之间由受限现金 24 解释。均为 USD million。[AMD FY2024 Form 10-K，财务报表及附注](https://ir.amd.com/financial-information/sec-filings/content/0000002488-25-000012/amd-20241228.htm)

AMD 来源指标待人工确认；非现金调整与营运资本现金变动等汇总值标为 Calculated，并保留公式。汇率影响尚未单独接入，相关规则保持缺失。

## 竞品可比性与差异化

已增加 NVIDIA / AMD 的历史财务差异矩阵及带来源的业务结构差异。收入占比不是市场份额，合并利润率不能直接证明某个产品竞争力；AMD 数据中心收入同时含 CPU 与 GPU，不能当成 GPU 市占率的分母。[AMD 年报](https://ir.amd.com/financial-information/sec-filings/content/0000002488-25-000012/amd-20241228.htm)

比较检查行业、呈报币种、准则、合并范围、年度起止、年度时长、审核状态和勾稽结果。币种/准则/范围/行业不一致、缺年度数据或报表不平时阻止直接比较。

严格模式要求期间完整且期末一致。可选相邻年度模式允许年末相差不超过 45 天，时长差不超过 7 天；这是研究产品策略，不是会计准则。NVIDIA FY2025 与 AMD FY2024 年末相差 29 天，仅标记“有条件参考”。NVIDIA 起始日尚未补齐时，严格模式拒绝直接比较。待审核数据不生成排名。

自建公司能加入财务矩阵；预置的定性差异说明仅覆盖三个案例。尚无证据的公司不自动生成竞争判断。当前比较表即时生成，未提供独立比较快照；研究者可在备忘录保存判断。

## 交互决策 / Decision log

| 用户任务 | 采用方案与取舍 |
|---|---|
| 不知道下一步 | 每页解释当前任务、输入及下一步；保留自由导航 |
| 不会写 JSON | Excel 两列粘贴，先展示单位标准化和勾稽，再确认保存；JSON 仍作为高级入口 |
| 不清楚按钮作用 | 动词说明结果；非交互指标不伪装成按钮；弹窗错误就近显示 |
| 参数太多 | 先展示增长、毛利与净经营费用率，高级参数折叠 |
| 害怕误改与丢失 | 导入预览不写库，参数修改提示未计算，快照解释修改原因 |
| 不喜欢配色 | 六套全界面预览；只在明确点击保存后持久化，不替用户选择 |

这些是降低记忆负担、逐步展示信息和及时反馈的设计假设。本轮没有用户行为实验，不能声称已证明符合所有用户心理或提高效率。

## 模型与支持范围

预置硬件平台和软件分组案例，加上 AMD 作为半导体对比。新公司基础预测以总收入为一个未拆分组，不伪装成完整业务分部。新年度到来后不会继续使用旧年度分组金额。

一般企业默认增长 10%、税率 20% 等为练习假设；费用率和部分资金占用来自已录入数据，缺失的折旧/资本开支等使用明确练习假设。银行等金融机构禁用一般企业 FCFF，只开放基础数据与相应勾稽。消费、医疗、互联网可建档录入，但尚无完整专属经营和估值模块。

行业分类、商业模式与指标字典可扩展；目前不支持自动抓取任意公司、PDF 自动抽取、跨准则自动调节、外汇换算、客户级经营数据库或完整三表预测。

## 实测与失败样本 / Evaluation

2026-09-19 实测通过：

- `tests/test_workbench.py`：28 项，包括手算现金流估值、PIT、错误勾稽阻止预测、单位转换、同标签不同日期拒绝、跨公司隔离、次年模型基数、预测币种、迁移保留记录。
- `scripts/qa-workspace.cjs`：新建消费公司 → 粘贴万元数据 → 预览归一 → 保存 → 勾稽 → 模型 → 刷新保留；竞品限制；色卡预览与保存区分。
- 十个页面在 1280 和 390 宽度无页面横向溢出、无浏览器脚本报错；宽表内部允许横向滚动。
- `scripts/qa-workbench.cjs`：原有审核、来源、模型快照、论点、后续披露、预测评价、备忘录、D 盘导出、文本注入转义、跨来源写请求拒绝、私有路径不可访问。

发现并修复：移动端网格子项撑开页面；对比说明不换行；自定义公司导出仍写 USD；旧固定公司模型基期；导入后因研究日期过早而用户看不见数据；弹窗错误被遮挡；新年度沿用旧分组。安全测试仅覆盖列出的情形，不代表全面安全认证。

浏览器测试用独立数据库，不污染用户研究资料和配色。用户资料库升级前已在 `.runtime/workbench/backups/` 备份。运行数据、导出、测试浏览器配置、缓存、截图均在 D 盘；没有主动修改 C 盘文件、安装依赖或变更全局配置。

## AI collaboration 与作品集表述

本轮 AI 完成原型代码、来源核对、测试与记录。用户明确提出多公司、财务逻辑、差异化比较、易用性和自主配色的产品要求；尚未把来源核验和设计验收记成用户已完成。后续需用户审核抽样数据、实际走一遍任务，并解释与纠正关键假设。

可据实描述交付多公司研究原型、确定性勾稽、可比性检查及 28 项程序测试。不能写准确率、研究效率提升或投资收益；也不能宣称企业内部经营能力已经验证。新增实现为项目代码；未复制 FinRobot 计算实现，沿用既有上游来源及许可证说明。
