# 演示与面试提纲

1. 打开 index.html，说明这是一版模拟原型，不是真实公司报告。
2. 点基期收入：展示口径、来源、日期和待审核状态。
3. 切换订阅软件：解释平均客户与硬件销量驱动不同，ARR 不等于收入。
4. 将研究日期调到 2026-02-28：输入不可用，情景输出隐藏。
5. 恢复日期，调整假设、填写理由、保存修订：展示前后值及原因。
6. 写下一个反证，导出备忘录到 D 盘。说明会话刷新不保留。
7. 展示复现失败日志及样例标签冲突，解释下一步怎样追踪字段和模板。

可诚实描述的成果：建立离线交互原型，设计两种业务驱动模型，4 项计算与边界测试通过，固定并检查指定上游版本。

不可描述的成果：完整自动研究平台、真实财务预测验证、高准确率、流程提效、企业内部经营分析、独立人工完成所有代码。
