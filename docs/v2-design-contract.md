# V2：市场理解如何进入财务预测

本轮目标：完成研究工作台的主要确定性功能，不把页面数量当作深度。展示财务分析、数据质量处理、市场研究推理、预测假设及可检验性。保持跨行业结构，使用 NVIDIA 与 Adobe 的历史披露作两种模式案例，不代表实时投资建议。

## 用户工作的先后顺序

研究问题 → 历史事实与商业结构 → 财务质量与增长贡献 → 市场驱动和反证 → 三情景假设 → 多年经营预测与估值敏感性 → 冻结预测 → 新资料验证或推翻 → 修订备忘录。

页面：研究总览、财务诊断、市场与论点、预测实验室、证据与审核、预测检验、研究备忘录。页面共享公司、研究时点、证据版本和研究记录，不互相孤立。

## 确定性功能验收

- SQLite 持久保存证据审核、市场论点、假设快照、预测记录、实际结果核验和备忘录。
- 指标带币种、单位、GAAP、期间、来源位置与审核状态；取数入口限制披露时间。
- 自动计算同比、利润率、现金转换、增长贡献与财务勾稽；缺失单独提示。
- NVIDIA 按数据中心与其余业务收入分组；Adobe 按三个业务分部。没有销量/客户明细，不编造销量价格或留存拆分。
- 五年分组收入模型，毛利/费用/税/D&A/资本支出/营运资金参数显式化；三情景、WACC 与终值敏感性。
- 真实债务/现金未接入的公司只输出企业价值，不伪造每股价值。全部估值是用户假设结果，不是推荐目标价。
- 市场论点包含机制、支持、反证、观察指标、推翻条件和关联参数；AI 未调用时如实显示。
- 新证据导入去重、不可改写旧记录；冻结预测记录完整输入。事后录入实际值只能评估同指标/期间/口径，回溯练习不能冒充前瞻预测。
- 本地 API 只监听回环地址；静态文件白名单；写操作验证 Origin 和会话 token；SQL 参数化；外部资料从不执行。
